# Personal Portfolio CMS

Tujuan proyek:

Membangun website portofolio modern yang seluruh kontennya dapat dikelola melalui dashboard admin.

Target:

- Responsive
- SEO Friendly
- Mudah diperbarui
- CRUD lengkap
- Authentication
- Image Upload
- Dark Mode
- Fast Loading

Stack

- Next.js
- TypeScript
- Tailwind
- Prisma
- PostgreSQL
- Supabase Storage
- Auth.js
- shadcn/ui

Fitur

Public Website

- Hero
- About
- Skills
- Experience
- Projects
- Contact

Dashboard

- Login
- CRUD Portfolio
- CRUD Skills
- CRUD Experience
- CRUD Contact
- Upload Image
- Site Settings

Deployment

- Vercel
- Supabase

Coding Style

- Clean Architecture
- Reusable Components
- TypeScript Strict
- No duplicated code
