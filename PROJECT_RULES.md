Rules

Semua kode menggunakan TypeScript.

Semua komponen menggunakan functional component.

Gunakan App Router Next.js.

Gunakan Server Component jika memungkinkan.

Gunakan Client Component hanya jika diperlukan.

Semua CRUD menggunakan Server Actions.

Tidak boleh menggunakan any.

Gunakan Zod untuk validasi.

Gunakan Prisma ORM.

Gunakan shadcn/ui.

Gunakan Tailwind.

Semua API harus memiliki error handling.

Semua form menggunakan React Hook Form.

Selalu gunakan loading state.

Selalu gunakan toast notification.

Semua halaman responsive.

Semua file diberi komentar seperlunya.
